## Air Quality UI (add-on)

**Ingress-safe assets:** The UI no longer depends on loading `static/style.css` or `static/profile-editor.js` via `<link>` / `src` URLs. Those are now read at server startup and **embedded** in the HTML (`<style>` in the base layout, `<script>` on the threshold profiles page).

Home Assistant ingress often serves the add-on at paths like `…/profiles` **without** a trailing slash. Browsers resolve relative URLs like `static/style.css` against the **parent** path segment, so the requested URL missed the add-on prefix and returned 404 — **no CSS** and **no JavaScript** for the band editor (plain inputs, black circles as unstyled handles, reference text as an unstyled run-on line).

After upgrading to **0.8.3**, every page includes full styling; the profiles page includes the threshold editor script with no extra network request.
