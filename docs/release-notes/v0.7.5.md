## Managed dashboard

- **Household** section at the top with badges for home overall and home problem entities, plus a summary that lists room-level issues (e.g. which room and measurement is poor, stale, or unavailable) derived from each space overall sensor’s `attention_reasons`.
- **Measurements** use a grid of **tile** cards (one entity per tile) with value and **health** attribute, replacing the previous single Entities card.

Call **airquality.sync_dashboard** or reload the integration to regenerate the dashboard after upgrading.
