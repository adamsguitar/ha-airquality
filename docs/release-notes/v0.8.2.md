## Air Quality UI (add-on)

**Ingress fix:** v0.8.1 used `request.url_for('static', ...)` for stylesheet and script URLs. That generates paths like `/static/style.css` from the **site root**. Behind Home Assistant ingress, the add-on lives under a prefix (e.g. `/api/hassio_ingress/...`), so the browser requested `/static/...` on the HA host and got **404** — no CSS, and `profile-editor.js` never loaded (threshold page stayed as plain inputs only).

This release restores **relative** URLs: `static/style.css?v=0.8.2` and `static/profile-editor.js?v=0.8.2`, which resolve correctly under the ingress path. The `?v=` cache-bust query remains.

Update/rebuild the add-on and confirm the footer shows **0.8.2** and the UI is styled again.
