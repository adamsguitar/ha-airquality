# v0.7.4

## Lovelace `LovelaceData` compatibility

Recent Home Assistant core versions store dashboards under **`hass.data["lovelace"]` as a `LovelaceData` object** (attribute `.dashboards`) instead of a plain dict keyed by `"dashboards"`. Air Quality v0.7.3 incorrectly treated that as “no dashboards key” after setup.

Dashboard sync now accepts **either** shape (dict or dataclass-like with `.dashboards` / `.dashboards_collection`), so the managed Air Quality panel can be created without spurious repairs on normal HAOS installs.
