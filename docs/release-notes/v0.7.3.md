# v0.7.3

## Dashboard diagnostics

- Repairs for **Lovelace storage unavailable** now embed structured **diagnostics**: Home Assistant version, whether `frontend` and `lovelace` components are marked loaded, a short description of what is in `hass.data["lovelace"]`, and the specific failure (`configuration.yaml` read error, Lovelace setup returned false, or data still invalid after setup).
- Resolves misleading copy: generic “profile / YAML” text could appear **even when dashboards worked**, because dashboard sync classified some failures with empty placeholders and dropped the detailed `result.detail` message.
