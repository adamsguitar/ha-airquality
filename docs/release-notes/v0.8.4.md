## Air Quality UI (add-on)

**Fixed profile save (“Method Not Allowed”):** Form `action` attributes used relative URLs (`profiles/{{ name }}`, `space/...`). With Home Assistant ingress, the visible path is often something like `/api/hassio_ingress/&lt;token&gt;/profiles` **without** a trailing slash. Browsers resolve `profiles/default` against that URL by **replacing** the last segment, producing a URL that **loses** the ingress token prefix — the POST hit the Home Assistant `/api/` layer instead of the add-on, which responded with **`{"detail":"Method Not Allowed"}`**.

All form actions and primary nav links now use **`app_href(request, …)`**, which strips a trailing route segment (`/profiles`, `/discover`) when present and builds absolute paths rooted at the ingress base (`/prefix/profiles/default`, etc.), so POSTs always reach FastAPI.
