# v0.7.1

## Add-on ingress

- **POST redirects** no longer use absolute paths like `/`. Under Home Assistant ingress those sent the browser to the full HA UI instead of staying inside the Air Quality panel. Redirects are now **relative** (e.g. `./#area-…`, `discover`, `profiles`), so the panel stays on the add-on after saving.

## Integration reliability

- **`airquality.reload`** no longer returns HTTP 500 when a **post-reload refresh** fails (e.g. transient errors). Failures are logged; YAML still reloads.

## Managed dashboard visibility

- If the Air Quality dashboard **cannot be created or updated**, the integration now opens a **repair** issue (specific messages for Lovelace not initialized, sidebar path conflict, or other errors), sends a **persistent notification** once per layout change when details are known, and **logs at warning** when Lovelace is not bootstrapped (common when dashboards are disabled in the user profile).
