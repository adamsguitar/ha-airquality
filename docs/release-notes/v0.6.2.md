# v0.6.2

Patch release: last-sensor delete no longer breaks reload; clearer logs.

## Add-on

- Removing the last source entity from a room no longer leaves a space with an empty `slots` list. That invalid state could make JSON-schema validation fail and cause `airquality.reload` to return HTTP 500 while the YAML was already updated (broken ingress redirect back to HA).
- Log lines from the UI process now include timestamps. Uvicorn is started with `log_config=None` so library loggers (e.g. httpx) keep the same format.

## Integration & schema

- `airquality.reload` logs a full traceback if reload fails unexpectedly.
- Config schema: `space.slots` may be an empty array for round-trip resilience (synced copies updated).
