## Air Quality UI (add-on)

- **Rooms:** measurement slots use a **two-column grid** on wider screens (single column on small viewports).
- **Visual hierarchy:** clearer contrast between room cards, headers, slots, and entity rows.
- **Threshold profiles:** edit breakpoints in the UI with **numeric fields and sliders** kept in sync; **reference values** from the discovery-default bands are shown as static text and marked on each slider scale.
- **Profiles:** add a named profile (**duplicate** an existing one or start from discovery defaults); **save** validates ordering and YAML schema then reloads the integration. Profiles that used **`extends`** are **materialized** when saved (flat thresholds; inheritance link removed).
- Reload the integration or use the UI after upgrading if you rely on YAML-driven behavior.
