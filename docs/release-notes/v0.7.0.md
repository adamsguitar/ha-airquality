# v0.7.0

## Air Quality managed dashboard

- The integration creates and updates a **Lovelace** dashboard (sidebar: **Air Quality**) with core cards only: per-room sections, overall and problem badges, measurement rows, and live markdown for stale rooms and slots that need attention.
- Dashboard layout syncs when configuration or “attention” state changes; use the **`airquality.sync_dashboard`** service to force a refresh. Custom edits inside that dashboard may be overwritten.

## Display names and branding

- **Measurement labels** are centralized (`Temperature` for all temperature variants, etc.) in the integration and add-on UI.
- **HACS / integration** includes `icon.png`; the add-on uses the same artwork. Add-on sidebar icon uses **`mdi:weather-dust`** for consistency with the artwork style.

## Slot entity IDs

- New slot sensors get an explicit suggested `object_id` of `{measurement}_{area_id}` for clearer entity IDs (existing entities keep their current IDs until renamed in the UI).
