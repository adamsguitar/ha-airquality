## Air Quality UI (add-on)

- **Cache busting:** stylesheet and threshold editor script URLs now include a query string tied to the add-on version (`style.css?v=0.8.1`, etc.) so Home Assistant ingress and browsers load fresh assets after an upgrade instead of reusing an old cached copy.
- **Visible build:** the footer shows **Air Quality UI** plus the running version so you can confirm the container matches the add-on version in Supervisor.
- **Dockerfile:** copies `addon/config.yaml` into the image as `addon_config.yaml` so the server always knows the released version without reading `/data/options.json`.

Rebuild / update the add-on to pick up this release. After upgrading, confirm the footer reads **0.8.1**. If it does not match Supervisor’s version, the old container is still running.

Integration package version is kept in lockstep with the add-on per repository policy (no integration code changes in this release).
