# v0.7.2

## Dashboard creation (Lovelace)

- If dashboard sync runs before Home Assistant has populated `hass.data["lovelace"]` (startup ordering or similar), the integration now **loads the Lovelace (dashboards) component** via configuration YAML and `async_setup_component` before creating the Air Quality panel. This addresses spurious **dashboard_lovelace_not_ready** repairs on otherwise normal installs.
- Repair copy for that issue is clearer: user profile **Always show the dashboard**, `lovelace:` in configuration when using YAML mode, and reloading or calling **airquality.sync_dashboard** after fixing.
