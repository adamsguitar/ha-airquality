# v0.6.1

Patch release: safer reload behaviour after config problems and tighter add-on delete flows.

## Integration

- `airquality.reload` no longer surfaces as an HTTP 500 when loading the YAML fails after a bad edit or unknown `area_id`. The coordinator catches the load failure, logs it, and keeps the previously valid config so the coordinator continues running.

## Add-on

- Removing a sensor or measurement slot validates the mutated YAML before writing and reloading, matching add flows. Invalid YAML is not persisted and reload is skipped, avoiding needless integration errors.
